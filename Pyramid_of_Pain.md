# what is Pyramid of Pain?

- Pyramid of pain is concept in cybersecurity that shows how much pain attackers face when we block and detect them.
- It is introduced by David J. Bianco.
- in pyramid of pain it is easy to detect lower levels and also easy for attackers to change it and upper levels is difficult to detect and change for attackers.

---

## Structure 

1. Hash Values
2. IP Addresses
3. Domain Names
4. Network/Host Artifacts
5. Tools
6. TTPs (Top level – most powerful)


### 1. Hash Values

- hash is unique fingerprint of file for ex. MD5,SHA1 etc.
- it is not much painful for attackers because it is easy to change.
- attackers change the hash of malware this technique is called "hash evasion".


### 2. IP Address

- malwares mostly connects to command and control server.
- the problem is attackers can easily change the ip address by buying new server.
- as always it is not painful for attackers.


### 3. Domain Names

- attackers use domain for malware communication for ex. update-microsoft-security.com, secure-login-google.net etc.
- attackers can easily buy a new domain like abc-login.com, abc-login.net etc.
- and also use techniques like "Domain Generation Algorithm" DGA malware creates thousands of malwares daily.
- it is medium painful but still manageable for attackers.
