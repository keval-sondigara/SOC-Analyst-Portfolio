## what is Alert?

- Alert is kind of notification that is generated by security and monitoring team that indicated something abnormal is happend and requires attention.

---

## Properties of Alerts

1) Timestamp :- it indicates that When the event happened.

2) Source IP :- it indicates that from where the activity came.

3) Destination IP :- it indicates that which system was targeted.

4) Alert Severity :- it indicates that how serious alert is ex: low,medium,high and critical.

5) Alert rule :- it indicates the rule that triggered the alert.

6) Event details :- it shows the detail description of alert.

---

## How to pick the right Alert?

1) Based on Severity
- starts from critical and high alerts.

2) Based on Asset value
- check if there is any important system like database server, domain controller so investigate critical alerts first.

3) Based on Frequency
- check the frequency if there is 1 login attempt this is normal if over 100 login attempts something suspicious.
